RGAA 4.1 — what can be automated?

Every test of the 13 themes, classified as automatic, semi-automatic or manual. Official data from accessibilite.numerique.gouv.fr; the classification is this project's own estimate, not an official one.

Automatic A script can reach a pass / fail verdict from the page (DOM, CSS, source) with no human judgement.
Semi-automatic A script finds the elements and checks the technical part; a human confirms scope or relevance.
Manual Needs a human: reading, listening, keyboard or assistive-technology testing, or several pages.
